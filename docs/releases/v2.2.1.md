# RimeTranslate v2.2.1

## 中文

这是一个面向**安装体验和项目文档**的小版本更新，翻译核心逻辑保持 v2.2.0 的稳定行为。

### 更新内容

- README 重新整理：最重要的功能、下载和快速安装放到最前面；
- 增加 `中文 | English` README 切换；
- Release 包同时包含中文和英文 README；
- 新增详细中英文安装文档；
- 第一次安装、且不存在 `rime_ice.custom.yaml` 时，安装器会自动创建所需配置；
- 已存在个人 `rime_ice.custom.yaml` 时不会覆盖，改为生成待合并模板并提示详细文档；
- README 新增本地 AI 架构的可扩展性说明。

### 安装

普通用户请下载：

```text
RimeTranslate-v2.2.1-windows-x64.zip
```

ZIP 内部已经包含顶层 `RimeTranslate` 文件夹。推荐直接解压到：

```text
C:\Users\你的用户名\
```

然后双击 `Install.cmd`，最后重新部署小狼毫。

## English

This is a small **installation/documentation update**. The core translation behavior remains aligned with v2.2.0.

### Changes

- Reorganized README with the key workflow first;
- added `中文 | English` README navigation;
- included both Chinese and English README files in the Release package;
- added detailed installation guides in both languages;
- the installer now creates the required `rime_ice.custom.yaml` automatically for first-time users when the file does not exist;
- existing customized YAML files are never overwritten; a merge template is created instead;
- added an extensibility section describing other local-AI candidate enhancement use cases.

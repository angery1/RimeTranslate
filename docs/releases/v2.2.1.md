# RimeTranslate v2.2.1

## 中文

这是一个以**首次安装体验、文档和项目展示**为主的小版本更新，翻译核心逻辑保持 v2.2.0 的稳定行为。

### 本次更新

- README 重新整理：功能效果、下载和快速安装前置，复杂说明移入 `docs/`；
- 增加 `中文 | English` README 切换；
- 加入项目在 Windows 上的三张真实运行截图：中文 → 英文、英文 → 中文、翻译开关；
- 新增模型与硬件资源说明 `docs/MODELS.md`；
- 给出三档模型建议：
  - 默认均衡：`gemma3:1b`
  - 低资源：`qwen2.5:0.5b`
  - 质量优先：`qwen2.5:1.5b`
- Release 包现在同时包含中文/英文 README、详细安装文档、模型说明和截图；
- 第一次安装且不存在 `rime_ice.custom.yaml` 时，安装器自动创建所需配置；
- 已有个人 `rime_ice.custom.yaml` 时不会覆盖，会生成待合并模板；
- 补充了“本地 AI 候选增强框架”的可扩展性说明。

### 安装

普通 Windows x64 用户请下载：

```text
RimeTranslate-v2.2.1-windows-x64.zip
```

Release ZIP 内已经有顶层 `RimeTranslate` 文件夹，推荐直接解压到：

```text
C:\Users\你的用户名\
```

然后双击 `Install.cmd`，最后执行一次“小狼毫 → 重新部署”。

> Ollama 必须安装，但无需保持 `ollama run` 终端常开，也无需设置 Ollama 开机自启动。RimeTranslate 会在有翻译请求时按需连接或启动 Ollama。

## English

This is a small release focused on **first-time installation, documentation, and project presentation**. The core translation behavior remains aligned with v2.2.0.

### Changes

- Reorganized README with screenshots, download, and quick-start instructions first;
- added `中文 | English` README navigation;
- added three real Windows screenshots: Chinese → English, English → Chinese, and the translation toggle;
- added `docs/MODELS.md` with model-size and hardware-resource guidance;
- model recommendations: `gemma3:1b` for the default balance, `qwen2.5:0.5b` for low-resource systems, and `qwen2.5:1.5b` for a quality-oriented setup;
- Release package now includes both README languages, detailed installation docs, model guidance, and screenshots;
- first-time Rime configuration is created automatically when `rime_ice.custom.yaml` does not exist;
- existing customized YAML is never overwritten;
- expanded the documentation around local-AI candidate-processing extensibility.

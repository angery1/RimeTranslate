# RimeTranslate

A lightweight Windows bridge that adds asynchronous Chinese ↔ English translation candidates to Rime/Weasel without blocking the Rime candidate-generation path.

Current release: **v2.2.0**.

Runtime prerequisites are installed separately: Rime Weasel, a Rime schema such as rime-ice, Ollama, and `gemma3:1b`. Third-party code and model weights are not bundled in this repository.
